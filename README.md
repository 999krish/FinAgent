
# FinAgent

## Overview

FinAgent is a research project investigating whether task-specialized multi-agent orchestration improves financial analysis compared with a controlled single-LLM baseline.

The project focuses on financial research, analytical correctness, evidence traceability, reliability, and quality-cost trade-offs.

## Research Question

Does task-specialized multi-agent orchestration improve the correctness of financial analysis compared with a controlled single-LLM baseline under equivalent information and tool-access conditions?

## Research Status

Early research and technical setup.

The research tasks, datasets, architecture, and evaluation methodology remain provisional and will be refined through literature review and academic supervision.

## Systems Under Comparison

1. Controlled single-LLM baseline
2. Task-specialized multi-agent system

The comparison will aim to maintain equivalent information, retrieval, tools, context, and comparable token budgets.

## Repository Structure

- `docs/` — Research and technical documentation
- `src/` — Application source code
- `experiments/` — Experiment configurations and tracking
- `evaluation/` — Evaluation scripts and methodology
- `configs/` — Configuration files

## Reproducibility

Experiments should record model versions, prompts, configurations, seeds, token usage, cost, latency, and evaluation results.

## Disclaimer

This project is for research and educational purposes. It does not provide financial advice.
